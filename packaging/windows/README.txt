GrantTrace v2.5.1
=================

第一次使用：
1. 请先完整解压 ZIP。
2. 双击 Start-Demo.bat。
3. 等待 Demo 完成，查看自动打开的 HTML 报告。

无需安装 Python 或其他依赖。
若报告未自动打开，请双击窗口中显示的 HTML 文件。

如果 Windows 提示安全警告，请确认 ZIP 来自官方 GrantTrace 项目。
这是未签名的便携程序，请核对项目提供的 SHA256SUMS.txt。
